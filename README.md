# Attention-Based Image Captioning Pipeline

基于注意力机制的图像描述生成系统，采用CNN-RNN-attention-RL架构，实现端到端的神经网络图像描述生成。

## 项目背景

本项目旨在实现一个完整的图像描述生成系统，结合了计算机视觉和自然语言处理技术。系统使用卷积神经网络(CNN)提取图像特征，通过长短期记忆网络(LSTM)和注意力机制生成自然语言描述。

### 核心特性

- **端到端训练**：从原始图像到自然语言描述的完整流程
- **注意力机制**：动态关注图像不同区域，提高描述准确性
- **强化学习优化**：使用自临界序列训练优化非可微指标
- **可视化支持**：生成注意力热力图，提高模型可解释性

## 开发计划

### 第一阶段：基础模型开发 ✅（已完成）

已完成的核心功能：

- ✅ **模型架构**：CNN-LSTM基础模型（ResNet18 + LSTM）
- ✅ **词汇表管理**：支持动态构建，最大5000词汇
- ✅ **训练Pipeline**：完整的训练循环，支持验证集评估
- ✅ **测试Pipeline**：测试循环，计算BLEU分数
- ✅ **损失计算**：交叉熵损失，支持padding处理
- ✅ **优化器**：Adam优化器，支持学习率调度
- ✅ **评估指标**：BLEU-1/2/3/4分数计算
- ✅ **文本输出**：控制台输出示例caption（10个样本）

**输出信息**：
- 训练损失（每个epoch）
- 验证损失（每个epoch，如果有验证集）
- 学习率变化
- 测试损失
- BLEU分数（BLEU-1到BLEU-4）
- 示例caption（图像名称、真实caption、生成caption）

**训练结果（Epoch 200）**：
- 训练损失：4.31
- 验证损失：4.25
- 测试损失：4.30
- BLEU-1：70.04%
- BLEU-2：30.17%
- BLEU-3：6.80%
- BLEU-4：2.67%
