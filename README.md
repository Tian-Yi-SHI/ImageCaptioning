# Attention-Based Image Captioning Pipeline

基于注意力机制的图像描述生成系统，采用CNN-RNN-attention-RL架构，实现端到端的神经网络图像描述生成。

## 项目背景

本项目旨在实现一个完整的图像描述生成系统，结合了计算机视觉和自然语言处理技术。系统使用卷积神经网络(CNN)提取图像特征，通过长短期记忆网络(LSTM)和注意力机制生成自然语言描述。

### 核心特性

- **端到端训练**：从原始图像到自然语言描述的完整流程
- **注意力机制**：动态关注图像不同区域，提高描述准确性
- **强化学习优化**：使用自临界序列训练优化非可微指标
- **可视化支持**：生成注意力热力图，提高模型可解释性
